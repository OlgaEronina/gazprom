# Сайт «Газпром газораспределение Великий Новгород»

Это готовая страница-прототип. Она состоит из обычных файлов, поэтому её можно
открывать, копировать и редактировать без специальных программ.

## Из чего состоит сайт

| Файл | Что это |
|---|---|
| `index.html` | Сама страница: весь текст и порядок блоков. |
| `styles.css` | Внешний вид: цвета, размеры шрифтов, отступы. |
| `script.js` | Мелкие интерактивные вещи (плавная прокрутка). |
| `assets/` | Все картинки и иконки. |
| `README.md` | Эта инструкция. |

## Как просто посмотреть сайт на компьютере

Дважды нажмите на `index.html` — страница откроется в браузере.

## Как перенести проект на другой компьютер

Скопируйте **всю папку целиком** (на флешку, в облако, по почте — как любую папку).
Внутри все ссылки относительные, поэтому на другом компьютере ничего не сломается.

## Как изменить текст на странице

Самый простой способ — прямо на сайте GitHub (ничего устанавливать не нужно):

1. Откройте репозиторий проекта на github.com.
2. Нажмите на файл `index.html`.
3. В правом верхнем углу нажмите иконку карандаша («Edit this file» / «Редактировать»).
4. Нажмите `Ctrl+F` (или `Cmd+F` на Mac) и найдите нужный текст.
5. Измените текст — он обычно находится между `<...>` и `</...>`, например:
   `<h2 class="section-title">Пресс-центр</h2>` — здесь меняете только слово между тегами.
6. Внизу страницы нажмите зелёную кнопку **«Commit changes…»** и подтвердите.
7. Через 1–2 минуты изменения появятся на сайте.

> Важно: не меняйте слова внутри `<...>` (это служебные теги), меняйте только текст
> между открывающим и закрывающим тегом.

Локально (на своём компьютере) то же самое можно сделать в любом текстовом редакторе
(Блокнот, TextEdit, VS Code): открыть `index.html`, найти текст, изменить, сохранить.

## Как изменить цены в прейскуранте

Страница «Установка и поверка сигнализаторов загазованности» — это файл
`signallers.html`. Цены находятся в таблицах: найдите нужную сумму
(например, `4&nbsp;290,00`) и замените её. Обозначение `&nbsp;` — это
неразрывный пробел между тысячами, его лучше сохранять.

## Как заменить картинку

1. Положите новую картинку в папку `assets/`.
2. В `index.html` найдите строчку с нужной картинкой — она выглядит так:
   `<img src="assets/hero.png" ...>`
3. Замените `assets/hero.png` на имя вашего файла, например `assets/my-photo.jpg`.
4. Сохраните и опубликуйте (см. ниже).

## Как обновить сайт в интернете

Изменения, сделанные на GitHub, публикуются автоматически за 1–2 минуты.

Если правки делались на компьютере — их нужно загрузить обратно на GitHub:
на странице репозитория нажмите «Add file» → «Upload files», перетащите изменённые
файлы и нажмите «Commit changes».

## Как добавить слайд в слайдер

На странице два слайдера: хиро (под шапкой) и «Полезная информация».
Каждый слайд — это блок `<div class="slider__page"> ... </div>` внутри `.slider__track`.

- **Хиро-слайдер:** один слайд = одна картинка-баннер.
- **«Полезная информация»:** один слайд = сразу 4 картинки.

Чтобы добавить слайд, скопируйте целый блок `.slider__page` и вставьте его рядом
с другими внутрь `.slider__track`. Точки переключения и автопрокрутка заработают
сами, когда слайдов станет больше одного.

## Если что-то сломалось

Всегда можно вернуться к исходной версии: на GitHub у каждого файла есть история
изменений (кнопка «History»), где можно восстановить прежний вариант.
