Запрос на заключение договора на техническое обслуживание внутриквартирного газового оборудования (ВКГО)

Осуществлять подписание договоров о техническом обслуживании газового оборудования со стороны абонента возможно через Портал государственных услуг Российской Федерации (Госуслуги) с применением мобильного приложения «Госключ».

Уважаемый собственник (наниматель) помещения, для заключения договора о техническом обслуживании внутриквартирного газового оборудования в многоквартирном доме вам необходимо:

  • заполнить форму заявления с обязательным указанием паспортных данных и номера телефона для связи;
  • после получения заявления наш специалист свяжется с вами, подготовит договор и пригласит для подписания в удобное для вас время;
  • для подписания договора посредством электронно-цифровой подписи (ЭЦП) необходимо отметить соответствующий пункт. Подписание ЭЦП возможно через Портал Госуслуги с помощью мобильного приложения «Госключ». Обмен электронной версией документа выполняется по электронной почте, указанной в заявке.

На подписании договора при себе необходимо иметь следующие документы:

  • паспорт гражданина РФ, СНИЛС;
  • для собственника помещения — документ, подтверждающий право собственности на помещение;
  • для нанимателя — договор социального найма.
